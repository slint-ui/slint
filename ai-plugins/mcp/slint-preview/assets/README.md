# Preview Assets

`canvas-cursor.png` is the Visual Editor's `tools/editor/ui/assets/cursors/default-32.png` from Grida.
It uses the same `(14, 14)` hotspot and the included Apache 2.0 [license](LICENSE).

The SVGs come from [Lucide revision `22e6094bb533ac2b0ae3b592d2184da461ec1f4b`](https://github.com/lucide-icons/lucide/tree/22e6094bb533ac2b0ae3b592d2184da461ec1f4b/icons), the revision used by the Visual Editor.
Their stroke width changes from `2` to `1.6`, and `aria-hidden` keeps decorative icons out of control labels.

- `sliders-horizontal.svg`: preview tools.
- `message-square-plus.svg`: annotate.
- `sun.svg`: light appearance.
- `moon.svg`: dark appearance.

The included [license](LICENSE) covers ISC and the MIT terms for the Feather-derived `moon` icon.
