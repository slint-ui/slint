A ListView is like a <Link type="ScrollView"/> but it should have a `for` element, and the contents are
automatically laid out in a list.

In a ListView, elements are only instantiated if they are visible, which guarantees stable performance with a practically unlimited number of items.
<Link type="ScrollView"/> is more suitable for free-form content.

<CodeSnippetMD imagePath="/src/assets/generated/std-widgets-listview-example.png"  imageWidth="200" imageHeight="200"  imageAlt='listview example'>
```slint playground
import { ListView, VerticalBox } from "std-widgets.slint";
export component Example inherits Window {
    width: 150px;
    height: 150px;

    VerticalBox {
        ListView {
            for data in [
                { text: "Blue", color: #0000ff, bg: #eeeeee},
                { text: "Red", color: #ff0000, bg: #eeeeee},
                { text: "Green", color: #00ff00, bg: #eeeeee},
                { text: "Yellow", color: #ffff00, bg: #222222 },
                { text: "Black", color: #000000, bg: #eeeeee },
                { text: "White", color: #ffffff, bg: #222222 },
                { text: "Magenta", color: #ff00ff, bg: #eeeeee },
                { text: "Cyan", color: #00ffff, bg: #222222 },
            ] : Rectangle {
                height: 30px;
                background: data.bg;
                width: parent.width;
                Text {
                    x: 0;
                    text: data.text;
                    color: data.color;
                }
            }
        }
    }
}
```
</CodeSnippetMD>

## Properties

Same as <Link type="ScrollView"/>, and:

### flex-direction
<SlintProperty propName="flex-direction" typeName="enum" enumName="FlexboxLayoutDirection" defaultValue="column" propertyVisibility="in">
The direction in which the rows are placed.
With `column`, the first row is at the top.
With `column-reverse`, the first row is at the bottom and the rows stack upwards.
The list then starts scrolled to the bottom, and rows that don't fill the view stay at the bottom.
Use it for a chat, where the newest message is row 0 of the model.
In a [`StandardListView`](/reference/std-widgets/views/standardlistview/), the arrow keys, Page Up, Page Down, Home, and End follow the screen.
With `column-reverse`, Home selects the last row.

A `ListView` places its rows vertically, so `row` and `row-reverse` aren't supported.
`column-reverse` doesn't support setting `content-height`: the `ListView` computes it from the rows.

```slint {7}
import { ListView } from "std-widgets.slint";
export component Example inherits Window {
    width: 150px;
    height: 150px;

    ListView {
        flex-direction: column-reverse;
        for i in 100 : Text { text: "Row \{i}"; }
    }
}
```
</SlintProperty>

## Callbacks

Same as <Link type="ScrollView"/>.

## Functions

### ensure-row-visible(row: int, behavior: ScrollBehavior)

Call this function to scroll the list so that the row at index `row` is fully visible.
A row above the viewport, or a row taller than the viewport, ends up at the top edge.
Any other row ends up at the bottom edge.
A row that's already fully visible doesn't move, but a running scroll animation stops.
If `row` is out of range, the call does nothing.
Pass `ScrollBehavior.instant` to jump or `ScrollBehavior.smooth` to animate, see [`ScrollBehavior`](/reference/property-types/builtin-enums/#scrollbehavior).

```slint {9}
import { Button, ListView, VerticalBox } from "std-widgets.slint";
export component Example inherits Window {
    width: 150px;
    height: 150px;

    VerticalBox {
        Button {
            text: "Show row 42";
            clicked => { list.ensure-row-visible(42, ScrollBehavior.instant); }
        }
        list := ListView {
            for i in 100 : Text { text: "Row \{i}"; }
        }
    }
}
```
