`TabWidget` is a container for a set of tabs. It can only have `Tab` elements as children and only one tab will be visible at
a time.

## Properties

### current-index
<SlintProperty typeName="int" propName="current-index" defaultValue="0">
The index of the currently visible tab.

```slint "current-index: 1;"
TabWidget {
    current-index: 1;

    Tab {
        title: "First";
    }
    Tab {
        title: "Second";
    }
}
```
</SlintProperty>


### orientation
<SlintProperty typeName="enum" enumName="Orientation" propName="orientation" defaultValue="horizontal">
The orientation of the tab bar.
When set to `vertical`, the tab bar is placed to the left of the content.
The property must be constant.
For example:
```slint
TabWidget {
    in property <Orientation> foo;
    // orientation: foo; // error
    orientation: Orientation.vertical; //valid
    Tab {
        title: "First";
    }
}
```
</SlintProperty>

## Properties of the `Tab` element

### title
<SlintProperty typeName="string" propName="title">
The text written on the tab.

```slint 'title: "First";'
TabWidget {
    Tab {
        title: "First";
    }
}
```
</SlintProperty>

## Custom Headers

The experimental `header` slot replaces one tab's header while keeping its page content in the same declaration.
Enable the `interfaces` and `named-slots` experimental features.
The supplied component must provide `TabHeaderInterface` from `std-widget-interfaces.slint`.
Custom headers require a custom `bar`.

```slint no-test
TabWidget {
    bar << ApplicationTabBar { }
    Tab {
        title: "Downloads";
        header << DownloadsTabHeader { }
        DownloadsPage { }
    }
}
```

The widget supplies the header's `title`, `selected`, and `focused` inputs.
Emit `activated()` to select the page and focus its header.
Ordinary Tab children remain page content; only the header slot goes into the bar.
Individual headers don't need their own keyboard focus scopes; the bar manages keyboard navigation.

## Custom Bars

The experimental `bar` slot replaces the arrangement of all headers, including the default style's headers.
The supplied component must provide `TabBarInterface` from `std-widget-interfaces.slint` and accept the generated headers as children.

The widget supplies `tabs` and `orientation`, and connects `current-index` and `focused-index`.
Each `tabs` entry contains its `index` and `title`.
The bar must expose `focus-tab(index)` for header activation.
