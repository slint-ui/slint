`TabWidget` is a container for a set of tabs. It can only have `Tab` elements as children and only one tab will be visible at
a time.

Wrap a `Tab` in `if` or `for` to add and remove tabs at run-time:

```slint
import { TabWidget } from "std-widgets.slint";
export component Example inherits Window {
    in property <bool> show-settings;
    in property <[string]> documents: ["Lorem", "Ipsum"];
    TabWidget {
        for document in documents: Tab {
            title: document;
            Text { text: "Content of " + document; }
        }
        if show-settings: Tab {
            title: "Settings";
        }
    }
}
```

The `title` of a `Tab` in an `if` or `for` can only use the model data, the index, and properties declared outside of the `Tab`.
Set it with a binding: assigning it, or changing it in a state, is an error.

## Properties

### current-index
<SlintProperty typeName="int" propName="current-index" defaultValue="0">
The index of the currently visible tab.
When `if` or `for` removes tabs so that the index no longer refers to a tab, the last tab becomes current.
It becomes `-1` when no tab is left.

```slint "current-index: 1;"
TabWidget {
    current-index: 1;

    Tab {
        title: "First";
    }
    Tab {
        title: "Second";
    }
}
```
</SlintProperty>


### orientation
<SlintProperty typeName="enum" enumName="Orientation" propName="orientation" defaultValue="horizontal">
The orientation of the tab bar.
When set to `vertical`, the tab bar is placed to the left of the content.
The property must be constant.
For example:
```slint
TabWidget {
    in property <Orientation> foo;
    // orientation: foo; // error
    orientation: Orientation.vertical; //valid
    Tab {
        title: "First";
    }
}
```
</SlintProperty>

## Properties of the `Tab` element

### title
<SlintProperty typeName="string" propName="title">
The text written on the tab.

```slint 'title: "First";'
TabWidget {
    Tab {
        title: "First";
    }
}
```
</SlintProperty>
