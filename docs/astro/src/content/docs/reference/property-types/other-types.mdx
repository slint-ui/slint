## Keyboard input

### keys
<SlintProperty propName="keys" typeName="keys" defaultValue='empty keys'>
A keys represents a key combined with a list of modifiers.
This is the primitive type used to detect if a KeyEvent should trigger a given key binding.

Key bindings in Slint are based on **logical keys** — the character a key produces on the current keyboard layout — not the physical position of a key on the keyboard.
See <Link type="KeyBindingOverview" label="Key Bindings" /> for details.

`keys` values have the following member function:

#### to-string() -> string

Returns a platform-native description of the key combination.

```slint
export component KeysToString inherits FocusScope {
    undo := KeyBinding {
        keys: @keys(Control + Z);
        activated => { debug("UNDO") }
    }

    Text {
        text: "Press \{undo.keys.to-string()} to undo!";
        // Results in "Press ⌘Z to undo!" on macOS
        // Results in "Press Ctrl+Z to undo!" on other platforms
    }
}

```

## Animation
### easing
<SlintProperty propName="easing" typeName="easing" defaultValue='linear'>
The `easing` type allows defining an easing curve for animations.

To specify an easing curve, use the values from the `Easing` namespace. For example you can use `Easing.ease-out` or `Easing.ease-in-quad`. The namespace consists of the following names (see [`easings.net`](https://easings.net/) for a visual reference):

    -   `linear`
    -   `ease-in-quad`
    -   `ease-out-quad`
    -   `ease-in-out-quad`
    -   `ease`
    -   `ease-in`
    -   `ease-out`
    -   `ease-in-out`
    -   `ease-in-quart`
    -   `ease-out-quart`
    -   `ease-in-out-quart`
    -   `ease-in-quint`
    -   `ease-out-quint`
    -   `ease-in-out-quint`
    -   `ease-in-expo`
    -   `ease-out-expo`
    -   `ease-in-out-expo`
    -   `ease-in-sine`
    -   `ease-out-sine`
    -   `ease-in-out-sine`
    -   `ease-in-back`
    -   `ease-out-back`
    -   `ease-in-out-back`
    -   `ease-in-circ`
    -   `ease-out-circ`
    -   `ease-in-out-circ`
    -   `ease-in-elastic`
    -   `ease-out-elastic`
    -   `ease-in-out-elastic`
    -   `ease-in-bounce`
    -   `ease-out-bounce`
    -   `ease-in-out-bounce`
    -   `cubic-bezier(a, b, c, d)` as in CSS
    -   `spring(bounce)` as defined in <Link type="Spring Animation" label="Spring Animations" />

Additionally, in expressions of type `easing`, those names are available directly.

```slint
struct AnimationData {
    curve: easing,
}

component Custom inherits Rectangle {
    property<AnimationData> animation: {
        // Using the Easing namespace.
        curve: Easing.ease-in-circ,
    };

	animate x {
    	// In easing expressions the names are available via global scope.
    	easing: ease-out-bounce;
	}
}
```

## Interaction Types

### data-transfer
<SlintProperty propName="data" typeName="data-transfer" defaultValue='an empty data-transfer'>

A `data-transfer` value is the payload carried by drag-and-drop and clipboard operations.
It abstracts over the file-type transfer mechanisms supported by each platform.
It can carry plain text, an image, and a list of local file paths simultaneously.

The type is opaque in Slint code:
construct a `data-transfer` value and read its content via callbacks implemented in the host language.
See <Link type="DragAndDrop" /> for an end-to-end example.

### MouseCursor
<SlintProperty propName="mouse-cursor" typeName="MouseCursor" defaultValue='default'>
The `MouseCursor` type is used in the <Link type="TouchArea" label="TouchArea element"/>.

Set to one of the built-in shapes by specifying the name:

```slint
TouchArea {
    mouse-cursor: ew-resize;
}

TouchArea {
    mouse-cursor: MouseCursor.ew-resize;
}
```

## Geometry

### corner-shape
<SlintProperty propName="border-corner-shape" typeName="corner-shape" defaultValue="round">

A `corner-shape` is the shape of a <Link type="Rectangle" /> corner.
The corner's border radius sets its size, so a corner with no radius stays sharp whatever its shape.
Slint follows CSS `corner-shape`, where every shape is a superellipse of exponent `k`.
Only the Skia renderer draws corner shapes; the other renderers draw every corner round.

Set one of the named shapes, or `superellipse(k)` for any other exponent:

```slint
Rectangle {
    border-radius: 16px;
    border-corner-shape: bevel;
}

Rectangle {
    border-radius: 16px;
    border-corner-shape: superellipse(3);
}
```

- `round`: a quarter circle, `superellipse(1)`. This is the default.
- `squircle`: a smooth transition between round and square, `superellipse(2)`.
- `bevel`: a straight diagonal cut, `superellipse(0)`.
- `scoop`: a quarter circle cut into the corner, `superellipse(-1)`.
- `notch`: a square cut into the corner, the limit of `superellipse(k)` as `k` goes to negative infinity.
- `square`: a sharp corner, the limit of `superellipse(k)` as `k` goes to infinity.
- `superellipse(k)`: a positive `k` bulges the corner outward, a negative `k` cuts into it.

Use `corner-shape` within Slint code.
The generated Rust and C++ code exposes a public `corner-shape` property through an internal type that may change in any release,
and JavaScript and Python can't read or set it.

</SlintProperty>
