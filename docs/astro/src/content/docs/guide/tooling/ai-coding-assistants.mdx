The Slint plugin bundles two skills: `slint-plugin` for its documentation and preview tools, and `slint` for general development guidance.
The general `slint` skill works with or without the plugin and can also be installed independently.

The plugin and skills are available from the [slint-ui/ai-plugins](https://github.com/slint-ui/ai-plugins) repository.

<Tabs syncKey="ai-tool">
  <TabItem label="Claude Code">
  Add the Slint marketplace from GitHub and install the plugin:

  ```sh
  /plugin marketplace add slint-ui/ai-plugins
  /plugin install slint@slint
  ```

  Claude Code can then use both bundled skills when working with Slint projects.
  </TabItem>
  <TabItem label="Codex">
  Install the plugin from GitHub:

  ```sh
  codex plugin marketplace add slint-ui/ai-plugins
  codex plugin add slint@slint
  ```

  Start a new Codex chat after installation so it picks up the plugin-use skill.
  </TabItem>
  <TabItem label="Antigravity">
  Install the plugin from GitHub with the [Antigravity CLI](https://antigravity.google/docs/cli/):

  ```sh
  agy plugin install https://github.com/slint-ui/ai-plugins
  ```

  This installs into `~/.gemini/config/plugins/`, so the plugin is available in every project.
  Restart Antigravity afterward so it picks up the plugin-use skill.
  </TabItem>
  <TabItem label="GitHub CLI">
  If you have the [GitHub CLI](https://cli.github.com/) installed, `gh skill install` works for any supported agent — pick the one matching your tool:

  ```sh
  # Codex
  gh skill install slint-ui/ai-plugins slint --agent codex

  # Claude Code
  gh skill install slint-ui/ai-plugins slint --agent claude-code
  ```

  See [`gh skill install`](https://cli.github.com/manual/gh_skill_install) for the full list of supported agents (Cursor, Gemini CLI, Windsurf, and others). Restart your agent afterward so it picks up the new skill.
  </TabItem>
  <TabItem label="npx skills">
  Install the Slint skill into the current project with the [`skills`](https://github.com/vercel-labs/skills) CLI:

  ```sh
  npx skills add slint-ui/ai-plugins --skill slint
  ```

  This works for any agent supported by the `skills` CLI (Claude Code, Cursor, and others) and installs into the project's agent skills directory by default. Pass `-g` to install globally for all projects.
  </TabItem>
</Tabs>

## What Your Assistant Can Do

The plugin-use skill guides documentation lookup, previews, and displaying screenshots in the current host.
The general skill helps with `.slint` code and integration with Rust, C++, JavaScript, or Python.

For application debugging, the general skill includes guidance for the Model Context Protocol (MCP) server embedded in your running Slint application.
Once connected, the assistant can inspect the UI through its accessibility tree, drive it with mouse, touch, and keyboard input, and capture screenshots to check the result — built on Slint's existing accessibility and testing APIs, with no debugging hooks in your application.
