---
title: Struct Updates
description: Update struct fields using an explicit base or an inherited binding.
---

> **Note**: Struct updates and inherited field overrides are experimental and subject to change.
> Enable them with the `struct-updates` [experimental feature](../overview/).

## Updating Struct Values

Use `..base` last in a struct literal to retain fields from a preset.
Dotted paths change nested fields and keep their siblings.

```slint
struct Font { size: length, weight: int }
struct Appearance { font: Font, foreground: color }

export component Example inherits Window {
    private property <Appearance> preset: {
        font: { size: 16px, weight: 400 },
        foreground: black,
    };
    out property <Appearance> custom: {
        font.weight: 700,
        ..root.preset,
    };
}
```

The result has the base's struct type.
Assigning an entire nested struct replaces that field.
The base is evaluated once, followed by the overrides in source order.
Bindings remain reactive.
Fields must exist, have compatible values, and appear only once.
Overlapping paths such as `font` and `font.size` are rejected.

## Overriding Inherited Struct Fields

Use a dotted binding to change a field of an inherited struct property.
Group fields sharing a path with commas inside braces and a semicolon after the group.

```slint
struct Font { size: length, weight: int }
struct Appearance { font: Font, foreground: color }

component Label inherits Text {
    in property <Appearance> appearance: {
        font: { size: 16px, weight: 400 },
        foreground: black,
    };
    font-size: root.appearance.font.size;
    font-weight: root.appearance.font.weight;
    color: root.appearance.foreground;
}

export component Example inherits Window {
    Label {
        appearance.font { size: 22px, weight: 700 };
        appearance.foreground: #0f766e;
        text: "Hello";
    }
}
```

Omitted fields retain the nearest inherited binding, or their struct defaults when no binding exists.
A whole-property binding such as `appearance: { font.weight: 700, ..preset };` selects an explicit base.
A whole-property binding and field overrides cannot target the same property on one element.
Overlapping overrides and inherited two-way bindings are rejected.

The [font and border example](https://github.com/slint-ui/slint/blob/master/examples/struct-updates/demo.slint) demonstrates these forms on custom components.
