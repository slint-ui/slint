---
title: UI Testing
description: Write automated system tests for your Slint application with the Slint UI Testing add-on.
---

Use [Slint UI Testing](https://testing.slint.dev) to write automated system tests for your application.
It launches your application locally or on a remote machine over SSH.
Your tests find elements in the UI, trigger actions such as clicking a button, and check the results.

Whichever language your application uses, you write the tests in Python.
For sample applications and test suites in Rust, C++, Node.js, and Python, see the [examples repository](https://github.com/slint-ui/ui-testing-examples).

:::note
Slint UI Testing is available as an add-on to your Slint license.
On the [pricing page](https://slint.dev/pricing), it's listed as `GUI Test Framework`.
:::

To set up your first test, follow the [UI Testing documentation](https://testing.slint.dev).
