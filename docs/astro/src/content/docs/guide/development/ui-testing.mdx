---
title: UI Testing
description: Write automated system tests for your Slint application with the Slint UI Testing add-on.
---

Use [Slint UI Testing](https://testing.slint.dev) to write automated system tests for your application.
It launches your application, either locally or on a remote machine over SSH.
Your tests find elements in the UI, trigger actions such as invoking a button, and check the results.

You write the tests in Python, whichever language your application uses.
Find sample applications and test suites for Rust, C++, Node.js, and Python in the [examples repository](https://github.com/slint-ui/ui-testing-examples).

:::note
Slint UI Testing is available as an add-on to your Slint license, listed as GUI Test Framework on the [pricing page](https://slint.dev/pricing).
:::

Follow the [UI Testing documentation](https://testing.slint.dev) to set up your first test.
