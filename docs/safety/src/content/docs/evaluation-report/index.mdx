**Addresses:** ISO 26262-8 11.5.1, from 11.4.1 to 11.4.5

This report evaluates the tools Slint SC provides: the Slint compiler and `slint-sc-coverage`.
Neither tool ships in the product.
The compiler writes code that ships, and `slint-sc-coverage` produces evidence.
The runtime ships, so it's not a tool; the [Component Documentation](/component-documentation/) covers the runtime.

* [Use Cases](/evaluation-report/use-cases/): how each tool is used in a project.
* [Potential Errors](/evaluation-report/potential-errors/): what can go wrong in each tool, and the measure or constraint that covers each error.
* [Tool Classification](/evaluation-report/tool-classification/): the confidence level each tool needs, derived from the potential errors and their detection.
* [Qualification Method](/evaluation-report/qualification-method/): how each tool reaches its confidence level.

The outcome of the qualification is in the [Tool Qualification](/qualification-report/tool-qualification/) chapter of the Qualification Report.

## Planning of Usage

11.4.4.1 asks us to plan the usage of each tool.

| | Slint compiler | slint-sc-coverage |
| --- | --- | --- |
| a) Identification and version | `slint-compiler` from `tools/compiler`, of the release under qualification | `slint-sc-coverage` from `tools/slint-sc-coverage`, of the release under qualification |
| b) Configuration | Built with the `slint-sc` feature, invoked with `--slint-sc` | Given the `.slintcov` maps the compiler writes with `--coverage`, and an `llvm-cov` export |
| c) Use cases | [UC_COMPILE_SLINT_FILE](/evaluation-report/use-cases/#compiling-a-slint-file-into-rust) | [UC_MEASURE_SLINT_COVERAGE](/evaluation-report/use-cases/#measuring-the-coverage-of-slint-code) |
| d) Environment | The build host | The build host, where the LLVM profiler runtime is available |
| e) Maximum ASIL | ASIL B, assumed; see [Integrity Level](/safety-plan/standards-compliance/#integrity-level) | ASIL B, assumed |
| f) Qualification methods | None required at TCL1; see [Qualification Method](/evaluation-report/qualification-method/#slint-compiler) | [Validation](/evaluation-report/qualification-method/#slint-sc-coverage) |

The maximum ASIL is an assumption, since Slint SC isn't developed for one specific product.
11.4.2 asks the integrator to verify the maximum ASIL before using the tools in their product.
