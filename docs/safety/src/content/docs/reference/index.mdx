This section documents the language and the API surface that Slint SC certifies.
The [Language Specification](/reference/language/) defines the language Slint SC accepts.
The other chapters document the elements, property types, rendering, touch input,
and the code the compiler generates.

Items in this reference are explicitly annotated as covered by Slint SC. Other
parts of the Slint language are documented in the [main Slint
documentation](https://slint.dev/docs/slint/) but are out of scope for safety
certification.
