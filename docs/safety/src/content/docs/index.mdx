Slint SC is the subset of Slint developed for safety-related software under ISO 26262, up to ASIL B.
Slint SC isn't released or certified yet, and these documents are a work in progress.

## Documents

* **[User Manual](/user-manual/)**: Start here if you build with Slint SC.
  Install it, compile your `.slint` files, and follow the rules that keep your application covered by the qualification.
* **[Reference](/reference/)**: Look up the language, the elements and properties, and the API of the generated code.
* **[Safety Plan](/safety-plan/)**: See how we develop, test, and release Slint SC.
* **[Tool Evaluation Report](/evaluation-report/)**: See why you can rely on the compiler and `slint-sc-coverage` in your safety project.
* **[Runtime Safety Documentation](/runtime/)**: Read the safety requirements of the runtime, and what can go wrong in it.
* **[Qualification Report](/qualification-report/)**: Check the evidence: test results, traceability, and coverage.
* **[Norm Mapping](/norm-mapping/)**: Find where these documents meet each requirement of ISO 26262.
