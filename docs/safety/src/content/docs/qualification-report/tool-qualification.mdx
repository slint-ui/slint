This chapter records the qualification of the tools evaluated in the [Tool Evaluation Report](/evaluation-report/).
ISO 26262-8 11.4.6.2 asks this chapter to state the following.

| Item | Slint compiler | slint-sc-coverage |
| --- | --- | --- |
| a) Identification and version | `slint-compiler` of the release under qualification; [Test Results](/qualification-report/test-results/) records the commit | `slint-sc-coverage` of the same release |
| b) Maximum TCL, and its evaluation | TCL1; see [Tool Classification](/evaluation-report/tool-classification/#slint-compiler) | TCL3; see [Tool Classification](/evaluation-report/tool-classification/#slint-sc-coverage) |
| c) Maximum ASIL | ASIL B; see [Planning of Usage](/evaluation-report/#planning-of-usage) | ASIL B |
| d) Configuration and environment | See [Planning of Usage](/evaluation-report/#planning-of-usage); [Test Results](/qualification-report/test-results/) records the toolchain | The same as for the Slint compiler |
| e) Who carried out the qualification | SixtyFPS GmbH | SixtyFPS GmbH |
| f) Methods applied | None required at TCL1, per 11.4.6.1 | [Validation](/evaluation-report/qualification-method/#slint-sc-coverage) |
| g) Results | [Test Results](/qualification-report/test-results/) and the [Traceability Matrix](/qualification-report/traceability-matrix/) | [Test Results](/qualification-report/test-results/) |
| h) Usage constraints and malfunctions | [Slint Compiler](/user-manual/compiler/), and [Known Problems](/user-manual/known-problems/) | [Coverage of Slint Code](/user-manual/slint-coverage/), and [Known Problems](/user-manual/known-problems/) |
