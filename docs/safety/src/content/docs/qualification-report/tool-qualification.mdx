**Addresses:** ISO 26262-8 11.5.2, from 11.4.6 to 11.4.9

This chapter records the qualification of the tools evaluated in the [Tool Evaluation Report](/evaluation-report/).
11.4.6.2 asks it to state the following.

| Item | Slint compiler | slint-sc-coverage |
| --- | --- | --- |
| a) Identification and version | `slint-compiler` of the release under qualification; [Test Results](/qualification-report/test-results/) records the commit | `slint-sc-coverage` of the same release |
| b) Maximum TCL, and its evaluation | Not settled yet; see [Tool Classification](/evaluation-report/tool-classification/#slint-compiler) | Not settled yet; see [Tool Classification](/evaluation-report/tool-classification/#slint-sc-coverage) |
| c) Maximum ASIL | ASIL B, assumed; see [Planning of Usage](/evaluation-report/#planning-of-usage) | ASIL B, assumed |
| d) Configuration and environment | See [Planning of Usage](/evaluation-report/#planning-of-usage); [Test Results](/qualification-report/test-results/) records the toolchain | The same |
| e) Who carried out the qualification | SixtyFPS GmbH | SixtyFPS GmbH |
| f) Methods applied | [Validation](/evaluation-report/qualification-method/#slint-compiler) | [Validation](/evaluation-report/qualification-method/#slint-sc-coverage) |
| g) Results | [Test Results](/qualification-report/test-results/) and the [Traceability Matrix](/qualification-report/traceability-matrix/) | [Test Results](/qualification-report/test-results/) |
| h) Usage constraints and malfunctions | [Compiler constraints](/user-manual/compiler/constraints/), and [Known Problems](/user-manual/known-problems/) | [Coverage of Slint Code](/user-manual/slint-coverage/), and [Known Problems](/user-manual/known-problems/) |
