## Clause 5: General Topics

| Requirement | Topic | Status | How |
| --- | --- | --- | --- |
| 5.4.1 | Suitable processes and environments | Partly met | [Development Process](/safety-plan/development-process/), and the [V-Model per Change](/safety-plan/lifecycle/#v-model-per-change), which keeps requirement, code, and tests consistent. The test suite script doesn't check yet that it runs on a qualified toolchain. Interaction with system and hardware development is the integrator's. |
| 5.4.2 | Criteria for selecting the language | Open | Slint SC is written in Rust, but the rationale against the criteria is missing. |
| 5.4.3 | Coding guidelines | Partly met | [Coding Standards](/safety-plan/coding-standards/); see [Table 1](/norm-mapping/iso-26262-6-methods/#table-1-coding-guidelines). |

## Clause 6: Software Safety Requirements

| Requirement | Topic | Status | How |
| --- | --- | --- | --- |
| 6.4.1 | Deriving the software safety requirements | Met | The [Assumed Safety Requirements](/runtime/assumed-safety-requirements/), refined by the paragraphs of the [Reference](/reference/); see [Safety Requirements](/safety-plan/standards-compliance/#safety-requirements). |
| 6.4.2 | What the specification considers | Partly met | The runtime has one configuration, accesses no hardware, and its external interfaces are the [Generated Code](/reference/generated-code/) and [Touch Input](/reference/input/). Timing constraints and operating modes aren't stated yet. |
| 6.4.3 | ASIL decomposition | N/A | Not used. |
| 6.4.4 | Hardware-software interface | N/A | The runtime accesses no hardware; see [Properties](/safety-plan/architecture/#properties). |
| 6.4.5 | Functions without safety requirements | Met | The runtime has no functions other than those the [Reference](/reference/) specifies. |
| 6.4.6 | Verifying the hardware-software interface | N/A | There's no hardware-software interface; see 6.4.4. |
| 6.4.7 | Verifying the software safety requirements | Partly met | Every requirement paragraph is reviewed with its pull request ([C-07](/safety-plan/development-phases/#on-every-change)). There's no record of what the review checked yet. |
