---
title: Deliverables
description: What each release of Slint SC delivers to integrators and to the assessor.
---

Each release delivers the following.
The documents of a release are signed.
The public site shows the unsigned draft built from `master`.

| Deliverable | Content | Who receives it |
| --- | --- | --- |
| Software | The `slint-sc` crate, the compiler with `--slint-sc`, and `slint-sc-coverage`, built from the baseline tag | Public |
| Safety Manual | This manual: [User Manual](/user-manual/), [Reference](/reference/), Safety Plan, [Tool Evaluation Report](/evaluation-report/), [Component Documentation](/component-documentation/), and [Qualification Report](/qualification-report/) | Public |
| Test suite for the target | The suites, packaged to run on the integrator's target; see [Tailoring](/safety-plan/standards-compliance/#parts-of-the-lifecycle) | Public |
| Safety case | The argument that the release meets its assumed safety requirements | Integrators and the assessor |
| Development interface agreement template | The activities that SixtyFPS and the integrator are each responsible for | Integrators |
| Release report | The signed record of the release | Integrators and the assessor |
| Assessment result | The TÜV Nord certificate, and the assessment report | The certificate is public; the report goes to integrators |
