# Lucide icons

These icons come from Lucide revision `22e6094bb533ac2b0ae3b592d2184da461ec1f4b`:

- [file-plus.svg](https://github.com/lucide-icons/lucide/blob/22e6094bb533ac2b0ae3b592d2184da461ec1f4b/icons/file-plus.svg)
- [image.svg](https://github.com/lucide-icons/lucide/blob/22e6094bb533ac2b0ae3b592d2184da461ec1f4b/icons/image.svg)
- [panels-top-left.svg](https://github.com/lucide-icons/lucide/blob/22e6094bb533ac2b0ae3b592d2184da461ec1f4b/icons/panels-top-left.svg)
- [pointer.svg](https://github.com/lucide-icons/lucide/blob/22e6094bb533ac2b0ae3b592d2184da461ec1f4b/icons/pointer.svg)
- [square.svg](https://github.com/lucide-icons/lucide/blob/22e6094bb533ac2b0ae3b592d2184da461ec1f4b/icons/square.svg)
- [type.svg](https://github.com/lucide-icons/lucide/blob/22e6094bb533ac2b0ae3b592d2184da461ec1f4b/icons/type.svg)

The viewer controls also use `check`, `chevron-down`, `monitor`, `plus`, `smartphone`, `trash`, and `x` from that revision.
`play-filled.svg` and `square-filled.svg` come from its `play.svg` and `square.svg`.

Each SVG changes `stroke-width` from `2` to `1.6` to match the editor's icon weight.
The two filled transport icons also change `fill` from `none` to `currentColor`.
Preserve these changes when updating the files.
