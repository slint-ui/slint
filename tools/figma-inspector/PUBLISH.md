# Publishing Figma to Slint

Run the release checks in [RELEASING.md](docs/RELEASING.md).
The assigned plugin ID is `1474418299182276871`.
`pnpm zip` requires the official release runtime pin; `pnpm zip:nightly` builds development snapshots and must not be submitted as a Community release.

Import the verified release manifest in Figma Desktop, signed in with the authorized Slint account.
Select the SixtyFPS GmbH team and use Plugins > Manage Plugins > Figma to Slint > Publish.
Confirm the publisher is SixtyFPS GmbH and the support contact is info@slint.dev.
Publication is a separate, explicitly authorized action.
