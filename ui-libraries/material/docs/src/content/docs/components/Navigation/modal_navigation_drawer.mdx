A `ModalNavigationDrawer` is a side panel that contains navigation items organized in groups, typically used for app navigation.

## Properties

### current-group
<SlintProperty propName="current-group" typeName="int" propertyVisibility="in-out">
The index of the currently selected navigation group.
</SlintProperty>

### current-index
<SlintProperty propName="current-index" typeName="int" propertyVisibility="in-out">
The index of the currently selected navigation item within the current group.
</SlintProperty>

### groups
<SlintProperty propName="groups" typeName="[struct]" structName="NavigationGroup">
An array of navigation groups, each containing a title and navigation items.
</SlintProperty>

### is-open
<SlintProperty propName="is-open" typeName="bool" propertyVisibility="out">
Whether the drawer is open.
</SlintProperty>

### position-right
<SlintProperty propName="position-right" typeName="bool">
Whether the drawer opens from the right edge instead of the left edge.
Defaults to `false`.
</SlintProperty>

### title
<SlintProperty propName="title" typeName="string">
The title displayed above the navigation groups.
</SlintProperty>

## Functions

### show()
Opens the drawer, preserving the current selection.

### close()
Closes the drawer without changing the current selection.

### select(group-index: int, item-index: int)
Selects the navigation item at the specified group and item indices, invokes `selected`, and closes the drawer.
Invalid indices are ignored.

## Callbacks

### selected(group-index: int, item-index: int)
Invoked when an item is selected. `group-index` is the index of the selected group and `item-index` the selected index in that group.

### item_pointer_event()
Emitted on any mouse pointer event similar to `TouchArea`. Arguments are the group and item index associated with the event, the `PointerEvent` itself and the mouse position within the `NavigationDrawer`.
